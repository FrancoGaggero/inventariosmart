Estado de avance al 05/11/2026

  1. Etapas 1 a 4 finalizadas: las 19 historias de las Fases 1, 2 y 3 están implementadas y desplegadas en la web, la API y la aplicación Android, más la portada con escenas 3D.
  2. El diseño de arquitectura y el DER base se hicieron antes de construir; cada historia tuvo su diseño de detalle antes de programarla, y los diagramas UML se consolidaron después de construir, a partir del sistema real. El proceso se explica en «07 Diseño técnico» y en la nota 2 del Gantt.
  3. 426 casos de prueba especificados; los automatizados corren en GitHub Actions en cada cambio, junto con el análisis estático y la compilación.
  4. Pendiente para la entrega: respaldo diario de la base con 30 días de retención (RNF-09, tarea 5.7), capturas del manual, video demo y la consolidación final de este formulario.
