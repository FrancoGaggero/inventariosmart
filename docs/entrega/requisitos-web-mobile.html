InventarioSmart · Requisitos funcionales Web y Mobile (APK)

Versión 1.0 · 9 de octubre de 2026 · Franco Gaggero · Tarea 3.1 del Gantt. Fuente: Propuesta v3.0 §3.1, especificaciones de OpenSpec (openspec/specs) y ADR 0024.

1. Criterio de distribución

La web y la aplicación Android consumen la misma API REST (/api/v1), con la misma autenticación, los mismos roles y los mismos planes, de modo que una operación tiene el mismo resultado desde cualquiera de los dos clientes. Lo que cambia es qué pantallas ofrece cada uno.

Van a la aplicación Android las tareas que se realizan en el mostrador o fuera del local, que entran en una pantalla chica y duran menos de un minuto. Lo que exige comparar tablas, cargar planillas o revisar muchos productos a la vez queda en la web (ADR 0024). La pestaña «Más» de la aplicación indica qué se hace desde la web.

3. Requisitos funcionales de la web

La web implementa los veinte requisitos funcionales (RF-01 a RF-20). Es la herramienta de gestión: carga inicial, proveedores, gastos, análisis, remarcación, configuración del comercio, usuarios y plan.

CódigoRequisito funcional webRF
RFW-01La web debe permitir registrarse, iniciar sesión con email o Google y completar el alta del comercio.RF-11, RF-15
RFW-02La web debe permitir al Dueño invitar usuarios, asignarles un rol y desactivarlos.RF-11
RFW-03La web debe permitir el ABM de productos con búsqueda, filtros por estado de stock y paginación.RF-01, RF-02
RFW-04La web debe permitir importar productos desde una planilla .xlsx o .csv con vista previa de errores antes de confirmar.RF-08
RFW-05La web debe permitir registrar ventas, ingresos y ajustes, consultar el historial con filtros y anular un movimiento mediante un ajuste.RF-13, RF-02
RFW-06La web debe permitir el ABM de proveedores y la carga manual o importación de listas de precios, con el historial de costos por producto.RF-03

5. Fuera del alcance de la aplicación Android

Importación de planillas, proveedores y listas de precios, comparador, gastos operativos, remarcación en lote, precios frente a la inflación, reportes semanales, edición de un producto existente, gestión de usuarios y cambio de plan. Se realizan desde la web, que la aplicación indica en «Más».
